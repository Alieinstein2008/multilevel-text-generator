
# Fonte do dicionário lexical

O dicionário utilizado neste projeto é derivado do **TeP 2.0 — Thesaurus Eletrônico para o Português do Brasil**.

## Fonte

- Repositório utilizado: https://github.com/stavarengo/portuguese-brazilian-synonyms
- Recurso original: https://hdl.handle.net/21.11129/0000-000D-F943-F
- Licença informada para o TeP 2.0: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

## Referência acadêmica

Maziero, E. G.; Pardo, T. A. S.; Di Felippo, A.; Dias-da-Silva, B. C. (2008). A Base de Dados Lexical e a Interface Web do TeP 2.0 — Thesaurus Eletrônico para o Português do Brasil. Anais do VI Workshop em Tecnologia da Informação e da Linguagem Humana (TIL), pp. 390–392.

## Modificações realizadas

- Conversão das relações lexicais para um arquivo JSON.
- Separação das relações de sinonímia e antonímia.
- Inclusão das relações inversas para facilitar consultas pelo sistema.

Os arquivos derivados do recurso lexical devem respeitar as condições da licença aplicável.
